# 써 본 분께 묻는 네 가지 (관문용)

리포트(또는 상시판)를 써 보신 뒤 한 줄씩만 답해 주세요. 숫자·이름은 안 적으셔도 됩니다.

1. 사흘 뒤에도 켜 두셨나요? (예 / 아니오 / 리포트만 한 번)
2. 이 값이면 사시겠어요? (예 / 아니오) — 값은 대표가 정한 뒤 채움: `____`
3. 이게 없으면 무엇으로 한도를 보시나요? (공식 /usage, 다른 앱 이름, 안 봄 …)
4. 안 살 이유를 하나만 꼽는다면?

추가로(선택): 최근 30일 "한도에 걸린 창" 숫자와 "가장 아까운 한 번" 한 줄.

# Four questions (for the gate)

1. Was it still running three days later? (yes / no / ran the report once)
2. Would you buy it at this price? (yes / no) — price: `____` (to be set)
3. Without it, what do you use to watch limits? (/usage, another app, nothing …)
4. One reason you would not buy it.

Optional: your "limit windows hit" count for the last 30 days and the "costliest hit" line.
